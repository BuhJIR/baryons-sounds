# baryons-sounds

Звуковые паки для baryons. Приложение звуков не содержит и своих не принимает — ставит только паки отсюда.

- `packs/<pack>/` — звуки пака;
- `index.json` — паки, звуки (sha256, длительность, усиление до −3 dBFS) и слоты, куда звук можно назначить:
  обращение к пульту, удержание фона, тест экрана (внимание / пошёл / конец), загрузка.
- `build_index.py` — пересобрать `index.json` после изменения паков.
